# Bokhanteringssystem i ASP.NET Core

## Beskrivning

Detta projekt är ett enkelt bokhanteringssystem byggt med **ASP.NET Core MVC** och **Entity Framework Core**. Systemet låter användare hantera böcker, författare och låna böcker. Det inkluderar CRUD-funktionalitet (Create, Read, Update, Delete) för böcker och författare samt en relationsdatabas.

---

## Teknologier

Följande teknologier används i projektet:

- **ASP.NET Core MVC**: För att bygga webbapplikationen med en Model-View-Controller-arkitektur.
- **Entity Framework Core**: För att hantera databasoperationer och relationer.
- **SQLite**: Som relationsdatabas för att lagra data.
- **C#**: Som programspråk för backend-logik.
- **Razor Pages**: För att skapa dynamiska webbsidor.

---

## Funktioner

Projektet inkluderar följande funktioner:

- **CRUD för böcker, författare, kunder och lån**:
  - Skapa, läsa, uppdatera och radera böcker och författare.
- **Hantering av relationer**:
  - Hantera relationer mellan böcker och författare.
- **Formulärhantering**:
  - Enkla formulär för att lägga till och redigera data.
- **Validering**:
  - Validering av formulärdata för att säkerställa korrekt inmatning.
- **Entity Framework Core**:
  - Användning av Entity Framework Core för databasinteraktion och hantering av entiteter.
